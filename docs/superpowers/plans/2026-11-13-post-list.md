# 게시글 목록 페이지 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/posts` 를 무한 스크롤 카드 피드에서, 썸네일(왼쪽) + 제목 + 설명만 보이는 30개 단위 번호 페이지네이션 목록으로 바꾸고 헤더·모바일 메뉴의 "게시글"을 연결한다.

**Architecture:** 쪽 번호(offset) 조회 + 전체 개수로 페이지를 나누고, 썸네일은 조회 때 `jsonb_path_query_first` 로 본문 첫 이미지 주소만 뽑는다. 쪽 번호 해석·번호 목록 계산은 순수 함수로 분리해 테스트한다. 기존 커서 피드 코드는 삭제.

**Tech Stack:** Next.js 16 (App Router, `searchParams` 는 Promise), drizzle, Lingui, Tailwind v4, vitest

**Spec:** `docs/superpowers/specs/2026-11-13-post-list-design.md`

## Global Constraints

- 한 줄에 썸네일 + 제목 + 설명만 (작성자, 작성일 등 표시 금지), 페이지 상단 제목·설명 문구 금지 (숨김 h1 만)
- 한 페이지 30개, 공개 글만, `published_at desc, id desc`
- 검색·필터·사이드 메뉴 없음, DB 스키마 변경 없음 (`db:migrate` 금지)
- Tailwind v4, 아이콘은 lucide 정적 SVG (`public/images/...`)
- 문구는 Lingui 매크로, `pnpm i18n:extract` 후 en.po 채우고 `pnpm i18n:compile`
- 앱 내부 링크는 `LocalizedLink`
- PC 기준 폭 1320px (`pc:` 접두사)

## Review Focus

- `?page=abc`, `?page=0`, `?page=-1`, `?page=1.5`, `?page=2&page=3` → 1쪽으로 해석 (배열이면 첫 값)
- 마지막 쪽보다 큰 쪽 → 404, 글이 0개면 1쪽에서 빈 목록 문구 (404 아님)
- 첫 이미지가 없거나 `src` 가 비었으면 기본 썸네일
- 페이지 수가 많을 때(예: 20쪽) 번호 목록에 첫·마지막 쪽과 현재 주변만, 사이는 `…` 하나
- 긴 제목·URL 같은 끊김 없는 문자열이 모바일에서 가로로 넘치지 않음 (`wrap-anywhere`, `min-w-0`)

### Task 1: 쪽 번호 순수 함수

**Files:**
- Create: `lib/posts/post-list.ts`
- Test: `lib/posts/post-list.test.ts`

**Interfaces:**
- Produces:
  - `POST_LIST_PAGE_SIZE = 30`
  - `parsePageParam(value: string | string[] | undefined): number` — 양의 정수 문자열(`/^[1-9]\d*$/`)이면 그 값, 아니면 1, 배열이면 첫 값 기준
  - `getPaginationItems(current: number, totalPages: number, siblings: number): Array<number | 'gap'>` — 1쪽, 마지막 쪽, `current ± siblings` 를 오름차순으로, 건너뛰는 구간마다 `'gap'` 하나. 단 건너뛰는 쪽이 딱 1개면 `'gap'` 대신 그 번호. `totalPages <= 1` 이면 `[]`
  - `getPostListHref(page: number): string` — 1쪽 `/posts`, 그 밖 `/posts?page=N`

- [ ] **Step 1: 실패하는 테스트**

```ts
expect(parsePageParam(undefined)).toBe(1);
expect(parsePageParam('3')).toBe(3);
expect(parsePageParam(['2', '5'])).toBe(2);
for (const bad of ['0', '-1', '1.5', 'abc', '', '01']) expect(parsePageParam(bad)).toBe(1);

expect(getPaginationItems(1, 1, 2)).toEqual([]);
expect(getPaginationItems(1, 5, 2)).toEqual([1, 2, 3, 4, 5]);

expect(getPostListHref(1)).toBe('/posts');

```
