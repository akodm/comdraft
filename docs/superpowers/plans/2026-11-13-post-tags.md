# 게시글 기술 태그와 작성자 GitHub 프로필 연결 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 초안·게시글에 기술 태그를 모으고(AI 분석 단계가 고르고 편집기에서 수정), 게시글 상세 작성자를 GitHub 프로필로 연결한다.

**Architecture:** 태그 규칙은 앱의 순수 함수 `normalizeTags` 하나. Lambda 분석 스키마에 `tags` 를 더해 완료 시 `draft_prompt.tags` 에 기록, 앱이 결과 반영 때 `draft.tags` 로 옮기고 게시 때 `post.tags` 로 복사. GitHub 아이디는 `user.github_login` 에 저장.

**Tech Stack:** 앱 — Next.js 16, drizzle, Better Auth, Lingui, Tailwind v4, vitest / Lambda — Node 22, zod, Anthropic SDK, `node:test`

**Spec:** `docs/superpowers/specs/2026-11-13-post-tags-design.md`

## Global Constraints

- 태그 규칙: 소문자, 앞뒤 공백 제거, 안쪽 연속 공백 → `-`, 최대 10개, 각 최대 30 코드 포인트, 빈 값·중복(정규화 뒤, 먼저 것 유지) 제거
- 태그 표시·필터·SEO 없음. 편집기 입력만
- AI 결과 태그가 비면 기존 `draft.tags` 유지, 빈칸 채우기는 태그 미변경
- 마이그레이션은 로컬만 `pnpm db:migrate:local` (운영 금지), Lambda 배포·terraform 금지
- Lambda 저장소에서 prettier 실행 금지. 앱 `useRouter` 직접 사용 금지, 내부 링크 `LocalizedLink`, 아이콘 lucide 정적 SVG
- 문구는 Lingui, `pnpm i18n:extract` → en.po 채움 → `pnpm i18n:compile`
- 실제 AI(Lambda/Claude) 호출 금지. 반영 확인은 `draft_prompt` 에 완료 작업을 직접 넣어서

## Review Focus

- 한글 조합 중 엔터로 태그가 반쯤 추가되지 않음 (`isComposing`)
- AI 작성 중(잠김)에는 태그 저장이 서버에서도 거절됨 (`lockingJobExists`)
- 게시된 초안 태그 변경 → 초안 상태 '임시', 사이드바·상단 상태 표시도 갱신
- AI 결과 반영 뒤 편집기 태그 칩이 새 태그로 바뀜 (`contentRevision` 변경 시)
- 이상한 `github_login`(빈 값, 형식 밖 문자)이면 링크를 만들지 않음

### Task 1: 태그·GitHub 아이디 순수 함수 (앱)

**Files:** Create `lib/posts/tags.ts`, `lib/posts/tags.test.ts`, `lib/posts/github-profile.ts`, `lib/posts/github-profile.test.ts`

**Interfaces — Produces:**
- `MAX_TAGS = 10`, `MAX_TAG_LENGTH = 30`
- `normalizeTag(value: string): string` — 규칙 적용(30 코드 포인트로 자른 뒤 끝 `-` 제거), 쓸 글자 없으면 `''`
- `normalizeTags(values: unknown): string[]` — 배열이 아니면 `[]`, 문자열만, 정규화·빈 값·중복 제거, 앞 10개
- `addTag(tags: string[], input: string): { status: 'added'; tags: string[] } | { status: 'empty' | 'duplicate' | 'full' }`
- `getGithubProfileUrl(login: string | null): string | null` — `^[A-Za-z0-9](?:[A-Za-z0-9-]{0,38})$` 일 때만 `https://github.com/{login}`

- [ ] **Step 1: 실패하는 테스트**

```ts
expect(normalizeTag('  React Native ')).toBe('react-native');
expect(normalizeTag('Next.js')).toBe('next.js');
expect(normalizeTag('C#')).toBe('c#');
expect(normalizeTag('   ')).toBe('');
expect(Array.from(normalizeTag('a'.repeat(40))).length).toBe(30);
expect(normalizeTags(['TypeScript', 'typescript', '', 'react', 3])).toEqual(['typescript', 'react']);
expect(normalizeTags('x')).toEqual([]);
expect(normalizeTags(Array.from({ length: 12 }, (_, i) => `t${i}`))).toHaveLength(10);
expect(addTag(['react'], 'React')).toEqual({ status: 'duplicate' });
expect(addTag([], '  ')).toEqual({ status: 'empty' });
expect(addTag(Array.from({ length: 10 }, (_, i) => `t${i}`), 'new')).toEqual({ status: 'full' });
expect(addTag(['react'], 'Vercel')).toEqual({ status: 'added', tags: ['react', 'vercel'] });
expect(getGithubProfileUrl('akodm')).toBe('https://github.com/akodm');
for (const bad of [null, '', '-abc', 'a b', 'a/b', 'x'.repeat(40)]) expect(getGithubProfileUrl(bad)).toBeNull();
```
