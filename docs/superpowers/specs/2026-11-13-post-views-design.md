# 게시 후 이동과 게시글 조회 수 집계 (짧은 설계)

## 의도

1. 게시하기·다시 게시가 끝나도 화면에 변화가 없어 됐는지 알 수 없다. 성공하면 그 글로 이동해 결과를 바로 보여 준다.
2. 나중에 인기·핫 게시글을 뽑기 위해 조회 수를 쌓아 둔다. 지금은 어디에도 표시하지 않고 집계만 가능하게 한다.

## 목표

- 게시하기·다시 게시 성공 시 같은 탭에서 게시글 상세(`getPostPath`)로 이동 (공개·일부 공개 모두)
- 상세 화면 조회를 기록하고, 기간별 조회 수를 SQL 로 바로 셀 수 있게 한다

## 하지 않을 것

- 조회 수 표시, 인기·핫 게시글 목록 (나중 작업)
- 게시글 사이 뉴스·광고 (나중 작업)
- 운영 DB 마이그레이션 적용 (사용자가 직접 함, 로컬만 적용)

## 정한 규칙 (사용자 결정)

- 같은 사람은 **30일에 한 번**만 센다 (마지막으로 센 때부터 30일이 지나야 다시 셈)
- **글쓴이 본인**의 조회는 세지 않는다

## 접근 방식

| 방식 | 장점 | 단점 |
| --- | --- | --- |
| **A. 센 조회만 한 줄씩 남기는 기록 테이블 하나 (선택)** | 테이블 하나, 어떤 기간이든 바로 셈, 나중에 기준을 바꿔 다시 뽑을 수 있음 | 줄 수가 센 조회 수만큼 늘어남 (커지면 날짜별 합계를 덧붙임) |
| B. 마지막으로 센 시각 테이블 + 날짜별 합계 테이블 | 조회가 가장 가벼움 | 테이블 둘을 함께 맞춰야 하고 개별 기록이 남지 않음 |
| C. `post` 에 누적 숫자 컬럼 | 가장 단순 | 기간별로 셀 수 없어 핫 게시글 용도에 안 맞음 |

사용자가 A 를 골랐다(저장 방식은 Claude 에게 맡김).

## 동작

- 테이블 `post_view(post_id, viewer_key, viewed_at)`: 센 조회만 한 줄. 게시글이 지워지면 함께 삭제
  - `(post_id, viewer_key, viewed_at desc)` 색인: 30일 안 기록 확인용
  - `(post_id, viewed_at)` 색인: 기간별 집계용
- 같은 사람 구분 `viewer_key`
  - 로그인: `user:{userId}`
  - 비로그인: `anon:{uuid}`. uuid 는 proxy 가 `/posts/...` 상세 요청에 쿠키가 없으면 새로 넣는 쿠키(httpOnly, 1년)
- 기록 시점: 상세 화면이 브라우저에서 열린 뒤 클라이언트 컴포넌트가 서버 액션 `recordPostView(postId)` 를 한 번 호출
  - JS 를 실행하지 않는 봇, 링크 미리 불러오기는 기록되지 않음
- 서버 액션 규칙 (하나라도 아니면 아무것도 하지 않음)
  - 게시글 ID 형식이 맞고, 게시된 글(공개·일부 공개)이 있음
  - 로그인 사용자가 글쓴이가 아님
  - 비로그인이면 형식이 맞는 viewer 쿠키가 이미 있음 (쿠키 없이 액션만 반복 호출하는 스크립트는 세지 않음)
  - 같은 `post_id + viewer_key` 로 30일 안에 기록이 없음
  - 동시 요청으로 두 번 세지 않도록 트랜잭션 안에서 `pg_advisory_xact_lock` 으로 `post_id + viewer_key` 잠금 후 확인·삽입
- 액션은 결과를 화면에 알리지 않음 (실패해도 조용히 끝남)
- 나중 집계 예: `select post_id, count(*) from post_view where viewed_at > now() - interval '7 days' group by post_id`

## 빌더에게 맡기는 것 (Claude 판단)

- 30일 판정·viewer_key 만들기 같은 규칙은 순수 함수로 분리해 테스트
- 쿠키 이름, 액션·컴포넌트 파일 위치
- 게시 후 이동은 `useLocalizedRouter().push(getPostPath(post))`, 이동 전에 확인 창 닫기
- 상세 화면의 기록 컴포넌트는 같은 글에서 한 번만 호출 (개발 모드 StrictMode 이중 호출은 30일 규칙이 막음)
- 마이그레이션은 `pnpm db:generate` 후 `pnpm db:migrate:local` 로 로컬에만 적용
